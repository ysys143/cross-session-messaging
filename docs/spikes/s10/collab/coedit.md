# 세 세션이 같은 문서를 고친다

이 폴더에서 너를 포함해 세 에이전트 세션이 동시에 일한다. 진행자는 없고, 단계도 없다.

## 과제

`ADR-DRAFT.md`는 이 프로젝트(xsm, 에이전트 세션 간 메시징)의 아키텍처 결정 기록 초안이다. 사실과
맞지 않는 곳, 근거가 약한 곳, 앞뒤가 어긋나는 곳을 찾아 **이 파일 하나를 고친다.** 참고 자료:

- `ref-agora-note.md` — 초안이 근거로 삼는 논문 조사 노트
- `ref-s10-spike.md` — 초안이 결정을 맡긴 실험 설계
- `ref-adr-0003.md` — 초안이 해석하는 제약(C1)의 원래 결정

고치는 것은 문서다. 새 파일을 만들지 말고 `ADR-DRAFT.md`를 직접 편집해라. 남은 시간은 `./timeleft`가
초로 알려 준다. 0이 되면 멈춘다.

## 다른 세션

    ./xsm list                          이 폴더의 다른 세션들 (이름과 ref)
    ./xsm send <이름 또는 ref:xxxxxx> --text "..."    한 세션에게 메시지
    ./xsm post --text "..."             이 폴더의 채널에 글 (셋 모두 읽을 수 있음)
    ./xsm channel                       채널 읽기

다른 세션이 보낸 메시지는 네 세션에 바로 들어온다. 네가 다음 입력을 기다리며 쉬고 있어도, 메시지가
오면 그것으로 깨어난다. 채널에 쓴 글은 아무도 깨우지 않는다 — 읽으러 와야 보인다.

`./xsm send`가 sandbox 거부를 돌려주면 xsm MCP 도구 `xsm_send`로 보내라. 같은 target, kind, text다.

이 폴더 안에만 써라.
