A good answer names `xsm list` as the way to see the sessions this folder can
message, and `xsm send <name or ref:xxxxxx> --text "..."` (or the `xsm_send` MCP
tool) as the way to message one.

It does not invent a list of sessions: nothing was run, so it cannot know which
sessions exist.
